Ever since I started using ChatGPT, Copilot, Promptless, and Claude, these AI tools have shifted my documentation workflows from manual drafting and formatting to high-speed generation that I then performed intensive editing and curation. Some examples of how I've used AI include:

| Use case                                        | AI tool    | Scenario |
|-------------------------------------------------|------------|----------|
| Created a guide from Slack conversations        | Promptless | [AI draft saved 99% of the time it would've taken me](/portfolio/most-impactful-tech-writing#ai-draft-saved-99-of-time) |
| Automated a workflow to draft Changelog entries | Claude     | [AI agent saved 83% of my Changelog writing time](/portfolio/most-impactful-tech-writing#ai-agent-saved-83-of-time) |

## Key changes in the documentation workflow

| Key change                    | Description |
|-------------------------------|-------------|
| Commoditized First Drafts     | AI handles the initial writing rapidly, cutting drafting time down significantly across technical, legal, and operational domains. |
| Shift from Writers to Editors | Human technical writers and managers now spend less time typing from scratch and more time reviewing AI output for hallucinations, tone drift, and accuracy. |
| Automated Capture and Process Recording | Tools like Scribe watch users perform on-screen tasks and automatically generate step-by-step visual guides and documentation in minutes. |
| Intelligent Metadata and Classification | Machine learning models automatically tag, classify, and structure content repositories, replacing manual filing and basic keyword searches. |
| Automated Gap Analysis    | AI systems scan existing documentation suites against new software releases or product updates to flag missing steps, outdated safety warnings, or broken procedures. |
| Custom AI Assistants      | Teams have moved from generic prompts to specialized, context-aware AI agents trained on proprietary knowledge bases or style guides (such as the Microsoft Style Guide) to maintain brand and technical consistency. |

## New challenges and risks

| Challenge              | Risk description |
|------------------------|------------------|
| The Review Bottleneck  | Because AI tends to write with confident, polished prose, subtle hallucinations or logic errors require more careful, time-consuming verification than obvious typos. |
| Multi-Step Degradation | Research from Microsoft and VentureBeat shows that delegating complex, multi-step workflows to AI can degrade or alter substantial portions of a document across extended chains. |
