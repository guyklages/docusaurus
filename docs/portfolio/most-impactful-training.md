| _Traditional_ style of learning: <br/> - Takes place in the same classroom. <br/> - 1 Teacher per 30 - 50 learners. <br/> - Teacher talks 90% of each 1-hour class. <br/> - Teacher talks from the front of the room. <br/> - Teacher writes on a board and mostly talks. | _Experiential_ style of learning: <br/> - Takes place at various venues related to the lesson topic. <br/> - 3 Facilitators per 21 - 30 learners. <br/> - Learners pair with other learners to talk 90% of each 2-hour class. <br/> - Facilitators walk around to answer questions and explain concepts. <br/> - Facilitators start activities and mostly listen. |
